# OUTPUT DIRECTORY

Thư mục này chứa output từ pipeline:

- `script.txt`     — kết quả từ Step 1 (Transcript/Idea → Script)
- `scenes.json`    — kết quả từ Step 2 (Script → Scene JSON)

Các file này được AI Agent (Claude hoặc Antigravity) tự động ghi sau mỗi bước.
Bạn có thể mở và chỉnh sửa trực tiếp trước khi chạy bước tiếp theo.
